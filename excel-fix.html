常见问题解答（FAQ）

Q：SafeExcelFix 会覆盖我原来的损坏文件吗？

不会。工具默认不修改原文件，修复成功后会生成一个带有 _SAFE.xlsx 后缀的新文件。

Q：为什么运行工具时提示缺少依赖或无法打开？

该工具的运行环境要求为 Windows x64 系统，并且需要安装 .NET Framework 4.8 或更高版本。请检查系统环境是否满足。

Q：修复后的文件里面的公式和宏还能用吗？

该工具主要清理安全风险和修复结构错误。对于文件结构本身已经严重损坏，或者涉及复杂宏（.xlsm）的文件，修复后可能存在部分高级功能丢失的情况，建议修复后先核对数据。
